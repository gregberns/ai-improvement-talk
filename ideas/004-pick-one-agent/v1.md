# Pick One Coding Agent and Commit

**Category:** `[foundation]`

## Symptom
Bouncing between tools — Copilot on Monday, Cursor on Tuesday, Claude Code on Wednesday. Never getting deep with any of them. "I keep trying different things."

## Root Cause
Breadth over depth. You can't build muscle memory or learn the edges of a tool you only use occasionally. Every tool has its own conventions, strengths, workflows. Spreading across them means you're always a beginner.

## Action
Pick one. Learn it deeply. Table stakes.

We recommend Claude Code, but the principle applies regardless. Commit to one tool and go deep. Learn its shortcuts, its quirks, its features. Become fluent in one before evaluating others.

## Connection to Model Choice
This pairs with "Stop model-hopping" — same principle applied to the tool layer. Stop experimenting, start committing.
