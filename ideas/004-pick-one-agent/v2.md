# Pick One Coding Agent and Commit

**Category:** `[foundation]`

## 1. Symptom

Bouncing between tools — Copilot on Monday, Cursor on Tuesday, Claude Code on Wednesday. Never getting deep with any of them. "I keep trying different things."

## 2. What to Change

Pick one. Codex, Claude Code, Gemini CLI — doesn't matter a lot. But pick one. Invest time in it. Focus on it.

If you're just playing around, fine, do whatever you want. If you are investing in your future — focus and do deliberate practice. Focus on getting incredible results with the best models available. Get your work done faster, with better code.

## 3. Reinforcing Patterns

- Commit for at least 2-3 weeks before evaluating
- Learn its shortcuts, quirks, features — become fluent
- Stop reading "X vs Y" comparison articles. You're procrastinating
- If your team uses something specific, start there — the tool matters less than the depth

## 4. Why What You Were Doing Wasn't Working

Breadth over depth. You can't build muscle memory or learn the edges of a tool you only use occasionally. Every tool has its own conventions, strengths, workflows. Spreading across them means you're always a beginner in all of them.

## 5. Why the Alternative Works Better

Depth compounds. Once you know a tool deeply, you stop fighting it and start leveraging it. The advanced techniques in later articles assume fluency with your tool — you can't do spec-driven work or sub-agent orchestration if you're still figuring out basic commands.
