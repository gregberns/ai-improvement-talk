# Session Continuity Without Context Rot

**Category:** `[context]`

## Symptom
You're deep in a feature. Context is getting full. You need to compact or clear, but you'll lose the thread.

## The Technique: Pre-Compaction State Files

Create two uncommitted files: `STATUS.md` and `TASKS.md`. Before compaction, tell Claude to update those files. They track where you're at and will survive compaction because they're on disk, not in context.

Hint: implement as a hook or command so it happens automatically.

## The Emergency Procedure

At 10% before compaction:
1. Stop everything
2. Tell Claude to save state to STATUS.md and TASKS.md
3. Write a compaction summary
4. Copy the summary
5. Run the clear command
6. Paste the summary and continue

## The Anti-Pattern

**Features that take more than one thread = ANTI-PATTERN.**

If you're regularly spilling across sessions for a single feature:
- You need sub-agents (idea 007) to conserve context
- You need to design first (specs, idea 010), then implement in a fresh session
- The design artifacts (spec, plan) are your handoff documents — they don't degrade with compaction
