# Kill Bad Sessions Immediately

**Category:** `[context]`

## Symptom
"Why is this session so bad!" The model is going in circles. It's not understanding you. It keeps making the same mistakes. You're frustrated.

## Root Cause
Context is poisoned. Once a session has gone south, the accumulated bad context (wrong approaches, misunderstandings, error output) is actively working against you. The model is trying to be consistent with everything in context — including the bad stuff.

## Action
STOP. Do not proceed. Kill the session. End it. Now.

Once a session has gone south it is very difficult to recover. Don't try.

1. Tell Claude to summarize what you were working on
2. Copy the summary
3. Run the clear command
4. Start new session with the summary

## Why Devs Resist This
Sunk cost fallacy. "I've been working on this for an hour, I can't just throw it away." But you're not throwing away the work — you're throwing away the bad context. The code changes are on disk. The summary carries forward what matters.
