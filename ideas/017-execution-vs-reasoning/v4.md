## 7 beats

### Beat 1 — Hook: the body game

- Pat head + rub belly, presented as interactive (reader tries it)
- Land: can't do both at once
- Bridge: neither can agents
- Short. The hook, not the lesson.

### Beat 2 — The model

- Name the two modes: reasoning and execution
- One-line each on what they do
  - Reasoning: investigates, thinks, plans
  - Execution: does — tool calls, code, fast
- Mental model: your message routes to one based on how it's written
- "This is a useful model, not literal architecture" caveat (one line — covers the router claim)
- Stay behavioral, don't go deep on internals

### Beat 3 — Split the 014 prompt

- Callback: "remember 014's prompt?"
- Show the split:
  - "Figure out how we'd implement this endpoint" → reasoning
  - "Now implement the plan" → execution
- One prompt, two modes, cleanly separated
- Optional: brief reference to 014's bad output ("that's what happens when you skip the split")
- Short; sets up beat 4

### Beat 4 — Your mirror

- You already do this in your own head
- Approach the problem, plan the steps, *then* type
- Routine tasks: seconds of mental planning before action
- Complex tasks: hours or days
- The agent can't do this automatically — you direct it
- Short. Introspection prompt for the reader.

### Beat 5 — The structural break

- You give yourself this break; give the agent the same break
- Plan phase, then execute phase
- Most work needs both phases
- Exception: small mechanical tasks (rename, typo) can skip the plan
- Judgment call: which mode fits which task
- Start simple: "plan first, execute second"

### Beat 6 — How to trigger and spot

**Signals — how to tell which mode the agent is in:**
- "Thinking..." indicator in most agents
- No tool actions, no printing, response delay = it's thinking
- Fast tool calls, immediate code = execution
- *You want to see the reasoning signals*

**Trigger reasoning:**
- "Think through this problem"
- "Help me understand"
- "How should we..."
- "Let's plan this out"
- Talk to it like a teammate, not a commander
- Many mechanisms — find what works

**Trigger execution:**
- Default mode — the agent wants to go there
- Commands, imperatives: "do this"
- Fine when you mean it (may still invoke reasoning when warranted)
- Concrete: "rename these variables" → instant response

Transition to beat 7: "Now how do you use this..."

### Beat 7 — Application / payoff

- Separating reasoning from execution = the foundation
- Small reliable steps stack into reliable processes
- Where the rest of the series goes
- Gesture toward series thesis — don't quote it
- One-sentence tail: sub-agents, specs, loops all use this
