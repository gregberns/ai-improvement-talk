# Encode Your Process — Meta

**Category:** `[workflow]` `[mindset]`

## Core Idea
Engineer your actual development workflow and thinking processes. You have a process for building features — what is it? Define it. Encode it. Have Claude help you formalize it.

## Why This Matters
This forces you to think really hard about what you actually do. You've spent years tuning your workflow — now make it explicit and reproducible.

If Claude isn't following the process — work with it to define and refine until it does.

## Getting Started
- Start by creating a command — good way to get your feet wet
- Say: "We're going to write this feature AND encode the process I use, so we can replicate it next time."
- Why not something off the shelf? Because if you don't know how it works and you aren't using it now, installing it won't help. Build understanding first.

## Example: This Very Project
This article series was built using the process: brain dump → refine each section → iterate → refine. Essentially a Ralph Loop applied to content, not code.

The talk itself was an example of the meta-process — using the process to build the thing that teaches the process.

## Connection to Mindset Change
This is the "meta" step. Not a technique — a way of thinking. It's later in the progression because it requires maturity with the earlier steps. You can't encode a process you haven't practiced.
