# Stop Model-Hopping. Best Model, Max Effort.

**Category:** `[foundation]`

## Symptom
"Tokens are expensive." "I want something cheaper." "I like OSS." "I'm using Copilot/Cursor/whatever because it's included."

## Root Cause
You're building a Formula 1 race car with a lawn mower engine. You're optimizing for the wrong thing.

## Action
Stop model-hopping. Claude Opus. HIGH effort. Tune it in.

DO NOT CONCERN YOURSELF WITH TOKENS. You do not think in tokens any more. NEVER AGAIN.

## Why This Is First
Everything else in this series assumes you're running the best available model at max effort. If you're penny-pinching on tokens or running a weaker model, none of the later steps will produce the results they should. The foundation has to be solid.
